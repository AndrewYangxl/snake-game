# 霓虹贪吃蛇

一个使用原生 HTML、CSS 和 JavaScript 制作的响应式贪吃蛇小游戏，无需安装任何依赖。

## 功能

- 方向键或 WASD 控制
- 悠闲、标准、极速三档难度
- 暂停、继续和重新开始
- 自动保存最高分
- 触屏方向按钮，支持手机游玩
- 可开关的轻量音效

## 开始游戏

直接用浏览器打开 `index.html` 即可。

也可以在项目目录运行一个本地服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / W A S D |
| 暂停或继续 | 空格键 |
| 重新开始 | 页面中的“重新开始”按钮 |

## 技术栈

- HTML5 Canvas
- CSS3
- 原生 JavaScript
